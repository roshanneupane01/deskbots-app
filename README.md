# DeskBots

Install on iPhone (no Mac, no App Store review):

1. On your iPhone, open this link in **Safari** (not Chrome):
   https://roshanneupane01.github.io/deskbots-app/
2. Tap Share (the square with the arrow).
3. Tap **Add to Home Screen**.
4. Open the DeskBots icon.
5. Settings → paste an OpenRouter key from https://openrouter.ai/keys

If the link 404s: GitHub.com → this repo → Settings → Pages → Source = Deploy from a branch → main / root → Save. Wait 1 minute.

This is a Home Screen web app. Apple will not let anyone put a random .ipa on your phone without a $99 developer account and a Mac.
